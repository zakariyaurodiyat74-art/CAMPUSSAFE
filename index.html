CampusSafe is a web-based campus security incident reporting and monitoring system designed to help students, staff, visitors and authorized security personnel report and manage security incidents efficiently.

ABOUT CAMPUSSAFE

Making Campus Security Smarter

CampusSafe provides a centralized platform where members of the university community can report security-related incidents and where authorized personnel can monitor, investigate and manage reported incidents.

OUR FEATURES

What CampusSafe Provides

01

Incident Reporting

Report theft, vandalism, suspicious activities, harassment, accidents, fire incidents and other campus security concerns.

02

Incident Monitoring

Authorized personnel can monitor reported incidents and follow their progress from submission to resolution.

03

Faster Response

Centralized reporting helps security personnel receive important incident information and respond more efficiently.

04

Role-Based Access

Different categories of campus users receive access according to their authorized account type and responsibilities.

HOW IT WORKS

Simple. Fast. Organized.

1

Create an Account

Register as a student, staff member, security personnel or visitor.

2

Report an Incident

3
